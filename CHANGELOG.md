# Changelog

All notable changes to `cf-mach` are documented in this file.

## 0.2.1

- Publish the existing `mach` network-quality CLI as the single crates.io package
  `cf-mach`.
- Consolidate the former private `nq-*` workspace crates into implementation modules;
  no `nq-*` package is published.
- Preserve the installed executable name and existing command surface as `mach`.
